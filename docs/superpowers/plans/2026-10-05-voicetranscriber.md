# VoiceTranscriber Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal macOS app that shows a live English transcript of computer audio or the microphone, answers questions about it during the session, and writes study notes with Claude when the session ends.

**Architecture:** A local Swift package (`Kit/`) holds all logic in four targets: `TranscriptCore` (pure Swift, no Apple media frameworks), `AssistantKit` (Claude client and prompts), `CaptureKit` (audio capture, recording, WhisperKit), and `SessionKit` (the session state machine, written against protocols so it can be tested with fakes). A thin SwiftUI app target (`App/`), generated by XcodeGen, holds the views, Settings, and Keychain access.

**Tech Stack:** Swift 6, SwiftUI, macOS 14+, Apple Silicon. ScreenCaptureKit, AVFoundation, WhisperKit (SPM), URLSession, Security (Keychain). Swift Testing. XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-05-voicetranscriber-design.md`

## Global Constraints

- Platform: macOS 14.0 minimum, Apple Silicon only. `platforms: [.macOS(.v14)]`. `CaptureKit` and `SessionKit` (and their tests and the WhisperKit dependency) are declared inside `#if os(macOS)` in `Package.swift`, so `TranscriptCore` and `AssistantKit` tests also run on Linux. Neither of those two targets may import Apple-only frameworks (AVFoundation, Security, ScreenCaptureKit).
- Swift language mode 6 (strict concurrency).
- Audio format inside the app: 16 000 Hz, mono, Float32.
- Whisper model: `large-v3-turbo`; decoding language forced to `"en"`.
- Claude model: `claude-opus-5-5`. Endpoint `https://api.anthropic.com/v1/messages`. Headers: `x-api-key`, `anthropic-version: 2023-06-01`, `content-type: application/json`, `anthropic-beta: server-side-fallback-2026-07-01`. Body always includes `"fallbacks": "default"`, `"thinking": {"type": "adaptive"}`, `"stream": true`.
- Ask: `output_config.effort = "low"`, `max_tokens = 4000`. Notes: `output_config.effort = "high"`, `max_tokens = 64000`, structured output `{title, notes_markdown}`.
- Transcript cache blocks: 5 minutes (300 s) each.
- Live decode interval about 1 s; decode window capped at 30 s; lag badge threshold 10 s; no-audio banner threshold 30 s.
- Claude retries: 2, exponential backoff (1 s, 2 s), for 429, 5xx, and network errors only.
- Default output root: `~/Documents/Transcripts/`. Folder name `yyyy-MM-dd HH-mm`, then `yyyy-MM-dd HH-mm <Title>` after notes.
- Transcript line format: `[mm:ss] text`; `[h:mm:ss] text` at or past one hour.
- The API key lives only in Keychain (service `VoiceTranscriber`, account `anthropic-api-key`). Never in files, logs, source, or tests.
- No feature that hides the app from screen sharing or proctoring.

## Review Focus

1. **No speech at all** (Stop pressed after 2 s, or a silent video): no Claude call is made; the session ends with "No speech detected" and the transcript files exist but are empty. → Test in Task 8 (`finalizeWithEmptyTranscriptSkipsNotes`).
2. **Folder name collision or unsafe title** (two sessions in the same minute; Claude returns a title with `/` or `:`): the folder gets a ` (2)` suffix; unsafe characters are replaced. → Tests in Task 4 (`createsSuffixOnCollision`, `sanitizesTitle`).
3. **Session longer than one hour**: timestamps switch to `h:mm:ss`; cache blocks keep their content unchanged once they are complete. → Tests in Task 2 (`formatsPastOneHour`, `completedBlocksAreStable`).
4. **Ask pressed before any final line exists**, or **no API key configured**: no network call; the Ask panel shows "Nothing transcribed yet" or "Add your API key in Settings"; recording continues. → Tests in Task 11 (`askWithEmptyTranscriptDoesNotCallAPI`, `askWithoutKeyReturnsMissingKey`).
5. **Claude refusal or a cut-off stream while writing notes**: `notes.md` is not written with partial or invalid JSON; the session shows **Generate notes**. → Tests in Task 10 (`refusalStopReasonSurfaces`) and Task 12 (`invalidJSONLeavesNoNotesFile`).
